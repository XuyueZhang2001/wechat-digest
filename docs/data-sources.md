# 数据源选型

本项目不绑定任何数据源。公众号没有公开 RSS，下面几条路各有取舍。

**最后更新：2026-11-14。** 价格、可用性和条款都可能变，以各官网为准。本文不构成推荐，作者与所列服务无隶属关系，也未使用任何返利链接。

## 对比

| 方案 | 费用 | 需要微信号 | 代码可审计 | 数据位置 | 覆盖 |
| --- | --- | --- | --- | --- | --- |
| Wechat2RSS 公开服务 | 免费 | 否 | — | 第三方 | 300+ 个号，仅最近文章 |
| DataXAPI | $0.02/次列表，$0.02/篇正文 | 否 | 否（SaaS） | 第三方 | 任意公众号 |
| Wechat2RSS 私有部署 | 订阅制（约 150 元/年，以官网为准） | **是** | 否（闭源镜像） | 本地 | 任意号，仅群发、最近 20 篇 |

## 1. Wechat2RSS 公开服务（免费）

- 收录 300+ 个公众号，列表见 https://wechat2rss.xlab.app/list/all.html
- 只输出最近文章，不提供历史回溯
- 不需要自己的微信号，运营风险最低
- 依赖第三方服务，可能变更或停止

适合：先用它验证流程，或只需要少数已收录的号。

## 2. DataXAPI（按次付费）

- 不需要微信号、不需要扫码
- 列表 $0.02/次，正文 $0.02/篇
- 数据经过第三方，适合不敏感的内容
- 需要 API Key，按量计费

适合：号不多、不想承担账号风险、能接受按次付费。

## 3. Wechat2RSS 私有部署（付费、自托管）

官方文档：https://wechat2rss.xlab.app/deploy/

事实：

- 软件以 Docker 镜像发布，**闭源**；GitHub 仓库只有文档和部署配置
- 需要 `LIC_EMAIL` / `LIC_CODE` 激活，激活会连验证服务器，传输邮箱、授权码和机器指纹
- 采集需要登录自己的微信号，存在被限流或封禁的风险，协议里已明确提示
- 数据存在本地；只抓群发消息、只保留最近 20 篇
- 协议限定个人学习研究，禁止商用、公开服务和二次分发

适合：需要较多公众号、能接受小号风险、愿意自己运维的人。

不适合：主微信号、公司环境、对外提供公开服务。

如果决定使用，至少做到：用小号、只绑 `127.0.0.1`、固定镜像 digest、加容器权限限制、不要把端口暴露到公网。

## 4. 不建议再用的方案

- **wewe-rss**：2026-05 归档，依赖的闭源中继已全端点 502，新部署走不通
- **we-mp-rss**：仍在维护，但容器出现过挖矿报告（issue #485），不建议跑在本机

## 通用建议

- 先用免费源把流程跑通，不够再考虑付费
- 付费 API 不需要微信号，账号风险最低；私有部署省的是单篇成本，付出的是账号和运维风险
- 无论用哪种，都把服务限制在本机，不要暴露公网
- 抓到的正文只用于个人分析，不要二次分发
