## 输出格式

严格输出以下 JSON 对象：

{
  "relevant": true,
  "relevance": 0.0,
  "summary": "用不超过 100 字概括本文围绕该事件说了什么",
  "angle": "技术 / 商业 / 供应链 / 政策 / 用户体验 / 行业格局 中的一个",
  "claims": [
    {
      "text": "一条可独立理解的判断，不超过 60 字",
      "type": "事实|解释|预测|观点|亲历",
      "evidence": "作者给出的依据，没有就留空",
      "quote": "逐字摘自正文的原文片段"
    }
  ],
  "open_questions": ["作者提出但未回答的问题"]
}

## 注意

- relevance 是 0 到 1 的小数，表示文章主题与该事件的相关程度。
- 只抽取与事件直接相关的判断。行业通识、背景介绍、其他公司的例子不要放进来。
- 最多 6 条 claims，按对理解该事件的重要性排序。
- 如果文章主要在讲别的事、只是顺带提到该事件，relevance 给低分，claims 只保留真正相关的那一两条。
